01

Motorsport Aero Simulator

Python · FastAPI · OpenFOAM · Three.js · Optuna

A Formula open-wheel aerodynamics workbench with three force tiers behind one interface: empirical, 3D vortex lattice, and a real RANS front-wing section that writes its own body-fitted mesh and reports measured y+.

A Bayesian optimiser searches wing angles, ride heights and diffuser angle. A validation ledger records every check against thin-airfoil theory — whether it passes or not.

Code Decision notes
"The point of this project is not the downforce numbers. It is that every result carries a provenance label."
